# 元辰起刻 · Kairote Studio

Kairote Studio 是一个由普通人组成的开发团队，主要做编程语言和编译器相关的工作。

## 项目

- **[Kairote_Lang](https://github.com/KairoteStudio/Kairote_Lang)** | 自研的编译型系统级编程语言，语法参考 C#
- **[Kortina](https://github.com/KairoteStudio/Kortina)** | 面向普通用户/开发者/KairoteLang的普通编辑器(可选IDE组件)
- **[Kortina_Website](https://github.com/KairoteStudio/Kortina_Website)** Kortina 官网
- **[DSRN_V1](https://github.com/KairoteStudio/DSRN_V1)** | 学术研究/实现尝试阶段的模型架构
