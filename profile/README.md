# 元辰起刻 · Kairote Studio

Kairote Studio 是一个由普通人组成的开发团队，主要做编程语言和编译器相关的工作。

## 项目

- **[Kairote_Lang](https://github.com/KairoteStudio/Kairote_Lang)** | 自研的编译型编程语言，语法参考 C#，编译器 Re.KrtC 用 C 编写、以 Zig 构建
- **[Kortina](https://github.com/KairoteStudio/Kortina)** | 面向普通用户/开发者/KairoteLang 的编辑器（Tauri + React），官网 Kortina.Website 也在本仓库
- **LitaMono** | 「Litalagica Mono」可变等宽字体（基于 JetBrains Mono），Kortina 的内置字体
- **[DSRN_V1](https://github.com/KairoteStudio/DSRN_V1)** | 学术研究/实现尝试阶段的模型架构
