## KairoteStudio 开源组织

在KairoteStudio，我们创建,贡献并支持开源项目。我们是KortinaIDE和KairoteLang背后的非营利开源组织，这两者都是开源项目


### KairoteStudio 在 GitHub 上

此组织汇集了我们参与开发并向社区提供的许多开源项目。每个项目都有一个标签，用于对项目类型进行分类：

### 行为准则

本行为准则概述了我们对所有参与开源项目和社区（社区计划）的人员的期望，以及对不可接受行为的后果。我们邀请所有参与者帮助我们为每个人创造安全、积极的体验。社区反映了其所处的社会，而积极行动对于应对社会中存在的各种不平等和权力滥用至关重要。

#### 如何行为
以下行为是对所有社区成员的期望和要求：

* 以真诚且积极的方式参与。这样做有助于维护本社区的健康和长久发展。
* 在言语和行动中保持体谅、尊重和同理心。请记住，我们在学习和采用技术时都经历过不同的阶段。
* 避免贬低、歧视或骚扰性的行为和言论。
* 对事物存在分歧是正常的，但争论性行为或恶意挑衅则不可接受。

#### 不应如何行为

* 不得实施暴力威胁或使用针对他人的暴力性语言。
* 不得开带有性别歧视、种族歧视、恐同、恐跨、歧视残障人士或其他歧视性质的玩笑，也不得使用此类性质的语言。
* 不得发布或展示露骨色情或暴力材料。
* 不得发布或威胁发布他人的个人身份信息（"人肉搜索"）。
* 不得进行人身侮辱，尤其是涉及性别、性取向、种族、宗教或残障的侮辱。
* 不得进行性方面的关注行为。这包括带有性意味的评论或玩笑以及性方面的示好。
* 不得提倡或鼓励上述任何行为。

请考虑到，在线社区汇聚了来自许多不同文化和背景的人。重要的是要理解，有时文化差异与在线互动相结合可能会导致误解。因此，保持同理心非常重要。

#### 如何报告问题

如果有人以任何形式行为不当或违反本行为准则，而他们不接受你的反馈，或者你不愿意与他们正面冲突，请通过 email 联系 KairoteStudio。

#### 不可接受行为的后果

任何社区成员的不可接受行为都不会被容忍。任何被要求停止不可接受行为的人都应立即遵守。如果社区成员从事不可接受的行为，KairoteStudio和/或社区组织者可以采取他们认为适当的任何行动，包括但不限于临时封禁或永久驱逐出社区，且无需事先警告。如有被广泛认为是不适当的行动,经认定后会撤回行动并予以对应的惩罚。
