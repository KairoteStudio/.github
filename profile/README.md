# 元辰起刻 · Kairote Studio

Kairote Studio 是一个由中学生组成的开发团队，主要做编程语言和编译器相关的工作。

## 项目

- **[Kairote_Lang](https://github.com/KairoteStudio/Kairote_Lang)** — 自研的编译型系统级编程语言，语法参考 C#
- **[Kortina](https://github.com/KairoteStudio/Kortina)** — 为 KairoteLang 开发的 IDE
- **[Kortina_Website](https://github.com/KairoteStudio/Kortina_Website)** — KairoteLang 官网
- **[DSRN_V1](https://github.com/KairoteStudio/DSRN_V1)** — 尚在开发中的 AI 架构
