## 我们是谁

**Kairote Studio（元辰起刻）** 是一支由中学生组成的开发团队，热衷于编程语言、编译器和系统级软件的研究与实现。我们相信年龄不是界限，热爱与坚持才是。

## 核心项目：KairoteLang

**KairoteLang** 是我们的旗舰项目 —— 一款现代系统级编程语言，拥有自研编译器工具链，涵盖前端、SSA 形式的中间表示以及多目标后端代码生成。

```krt
// KairoteLang 示例
Namespace HelloWorld;

using System;

public class Program
{
    public static void Main(string[] args)
    {
        Console.WriteLine("Hello, KairoteLang!");
    }
}
```
